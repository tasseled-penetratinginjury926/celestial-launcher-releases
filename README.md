## Overview
**Celestial Launcher** is a modern and reliable custom skin manager for **League of Legends**. 

It provides easy access to a wide collection of high-quality custom skins with automatic updates and a clean, user-friendly interface.

> [!Important]
> This tool is intended for custom skin usage only.

## Key Features
- One-click skin installation
- Large library of premium and custom skins
- Automatic updates & patch compatibility
- Fast and lightweight launcher
- Skin preview functionality
- Clean modern UI
- Regular addition of new skins
- Easy skin management system

## How to Use
1. Download the latest release
2. Extract the files
3. Run `Celestial.exe` as Administrator
4. Log in to your Riot account
5. Browse and install custom skins
