**Where do I find new skins?**
Several community websites host custom skins for League of Legends. Download the mod files from reputable sources. Ensure the files are meant for the current version of the game to avoid potential errors.

**The launcher cannot find my game.**
If you receive an error about a missing game path, click the settings icon in the top right corner. Use the folder browser to navigate to your Riot Games directory. Select the League of Legends folder to confirm the path.

**Can I run multiple skins at once?**
Yes, you can enable several skins at the same time. The launcher manages these layers and ensures they do not conflict. If two skins change the same model, the launcher will prioritize the one selected last.
